# 架构

```text
行情与公司行动 → 数据标准化 / 会话重采样 → 策略目标
                                                ↓
                                           交易事件账本
                                                ↓
                                      绩效指标 / 因子分析
                                                ↓
                                           HTML 报告
```

| 模块 | 职责 |
|---|---|
| `data.py` | 单位转换、公司行动调整和小时网格工具 |
| `frequency.py` | 会话重采样、缺失窗口标记和行情读取 |
| `strategies.py` | 内置目标序列、连续因子及参数网格 |
| `support_resistance.py` | 支撑反弹、压力突破、突破回踩及假跌破策略 |
| `engine.py` | 现金、份额、应收、订单、成交和公司行动账本 |
| `metrics.py` | 基于日终权益的绩效和风险指标 |
| `factor.py` | 时序相关、衰减与滚动分组检验 |
| `api.py` | 组合回测、基准、因子与报告的运行入口 |
| `report.py` | 生成单文件中文 HTML 并原子替换 |
| `research.py` | 区间划分、批量评估和滚动样本外研究 |

`etf_backtest.__all__` 定义顶层公开接口。策略只返回目标，引擎负责成交延迟、账户约束和事件处理，报告消费计算结果。

用户数据通过 `bars` / `events` 传入；不同市场的数据接入需要明确单位、交易时段与事件规则。`research.py` 批量函数接受 `ranges`，研究新数据时应显式提供日期区间。

`examples/` 包含可执行示例与日频样本，`tests/` 包含独立账本案例和集成测试。发行 wheel 仅安装 `etf_backtest`；从 Git 仓库或源码包运行示例。
