# 双频双区间回测实施记录

用户已批准完整方案并要求实施。新增子系统，不覆盖原始行情。

## 模块与接口

- `etf_backtest/data.py`：`prepare_data(root)` 返回 daily/60min 标准化行情、公司行动及质量报告；事件驱动的因果复权信号与原始价格账本分开。
- `etf_backtest/engine.py`：`run_backtest(bars, targets, config, events)` 返回 ledger/orders/fills/trades/actions；只接收0/1仓位，逐事件维护现金、可卖份额、分红应收。
- `etf_backtest/strategies.py`：四类策略生成器与小规模参数网格，均只向后观察。
- `etf_backtest/metrics.py`、`research.py`：日终指标、分区间研究、60/20/20分割及三年训练一年验证。
- `etf_backtest/plots.py`：可交互离线图表与报告；Notebook含独立完整README。

## 固定语义

资金100万元；佣金0.00005/边、最低0元；滑点0.0001/边；T+1、买入100份整手、无杠杆。日频下一日开盘；小时下一交易窗口VWAP于窗口结束结算。2022版预热可用更早行情，但资金和订单重置，区间内首个信号才可下单。收盘信号不在同根K线成交。期末不强平。

重点检验：缺整天小时数据、折算日零成交、登记日持有但支付日已卖出的分红、小时VWAP收益归属、跨区间参数与资金泄漏。不存在Git仓库，不创建提交。
