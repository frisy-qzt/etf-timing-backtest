# 双频双区间回测对抗审查

两路独立只读审查已完成（引擎与统计；数据与研究）。首次因账户额度失败，后续重试成功。

## 已修复

1. 日频开盘成交使用当日收盘、高低价和总成交量判断，造成对未来日内字段的依赖。现分离开盘与收盘状态；开盘只使用有效开盘报价、事前停牌及价格限制。容量上限日频使用前一完整日量。
2. 中途单根停牌令趋势/动量指标重新预热并强制空仓。现指标按有效K线计算，再对齐完整时间网格；无效根返回缺失信号，由引擎保留目标。
3. 折算停牌恰好缺15:00小时记录时，原始占位收盘可能覆盖折算后估值。现缺失日终只使用事件调整后的valuation_close。
4. 来源指纹不足。增加目标ETF源表、重建分钟证据和原始因子CSV的内容哈希。
5. Notebook字符串换行导致报告单元格语法错误。生成器逐个AST校验所有代码单元格；执行失败保存failed副本便于诊断。
6. 窄屏Plotly标题和双面板热图溢出。图表改为容器内横向滚动，保留可读尺寸；禁用云分享按钮，全部图表离线使用。

前三项各自先写失败回归用例，观察失败后修复。全套30项测试通过（包含原有数据测试）。

## 明确的模型边界

- 主回测使用开盘/VWAP价格代理，不限制市场容量；每笔参与率和容量压力实验随结果导出。
- 小时VWAP价格及总量于窗口结束才确定，属于窗口等价执行，不模拟逐笔订单簿。容量上限是整笔拒单情景，不是部分成交模型。
- 日频以前日总量衡量容量仅是参考，不能推断实际开盘集合竞价可成交量。
- 滚动折独立空仓初始化，其连乘曲线是评估指数，不代表持续持仓策略。
- 分红公告未说明分位舍入规则，保留完整计算精度并披露。
- 原始分钟ZIP未在当前项目中，分钟Parquet只能与本地其他频率及官方事件交叉核验。
