# 南方中证 1000 ETF 日频研究样本

代码 `512100.SH`，交易日期 2016-11-04 至 2026-09-30，共 2,408 行。由维护者提供的本地研究快照发布；不是实时行情服务，也不是南方基金官方发布的数据包。

| 文件 | 内容 |
|---|---|
| `512100.SH_daily.parquet` | 已完成单位归一化、带因果事件信号视图的日频研究表 |
| `corporate_actions.csv` | 一次份额合并、两次现金分红及原始公告 URL |
| `manifest.json` | 日期、单位、文件大小与 SHA-256 |

OHLC 为不复权价格，单位元/份；`volume` 为份，`amount` 为元。`volume_source` 和 `amount_source` 保留源值，分别为手、千元。`signal_*` 是仅使用已生效公司行动的信号价格，不能替代实际成交价。缺失、停牌、估值及质量字段保留原研究快照，demo 不将零成交日伪造为可交易日。

样本保留了原始涨跌停字段，包括历史异常占位值；非空字段覆盖不等于其经济有效性已获验证。该示例用于复现研究流程，不能据此声称已完整模拟历史涨跌停。

## 公司行动

- 2022-09-02 份额合并：每旧份转换为 0.36555 份，账户总份额向上取整；当日停牌。
- 2025-01-15 除息：每份 0.037 元，登记日 01-14、支付日 01-20。
- 2026-01-19 除息：每份 0.041 元，登记日 01-16、支付日 01-22。

CSV 的 `verified` 沿用维护者原研究记录；本次版本整理没有重新联网核验公告。每条事件提供 `source_url`，便于独立核对。样本期以后新增行情时必须同步新事件。

## 来源与权利

本样本按维护者的发布要求附带。原行情供应商和上游再分发许可未在现有资料中记录，因此本项目不为行情声明 MIT 或其他开放数据许可证。代码 MIT 与数据权利分开；使用者应自行核对适用的来源条款，不能从代码许可证推导数据的进一步再分发权。

项目只附带这一个明确命名的日频样本，不附带整个 ETF 数据湖、供应商因子包或公告 PDF。SHA-256 用于检测文件变化，不是来源真实性或授权的证明。

## 运行

在仓库根目录安装 `python -m pip install -e .` 后执行：

```bash
python examples/zz1000_daily_demo.py
python examples/zz1000_daily_demo.py --start 2022-01-01 --fast 10 --slow 30
```

输出 `output/zz1000/南方中证1000ETF_日频双均线report.html`；同名运行成功后会替换旧报告。默认初始资金 100 万元、佣金单边 0.5bp、滑点 1bp、下一日开盘执行、T+1，不作收益承诺。
