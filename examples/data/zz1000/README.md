# 512100.SH 日频样本

南方中证 1000 ETF，覆盖 **2016-11-04 至 2026-09-30，共 2,408 行**。

| 文件 | 内容 |
|---|---|
| `512100.SH_daily.parquet` | 日频价格、成交量额、事件因子和信号价格 |
| `corporate_actions.csv` | 公司行动、日期、参数及公告 URL |
| `manifest.json` | 数据范围、单位、文件大小和 SHA-256 |

## 字段与单位

OHLC 为不复权价格，单位元/份；`volume` 为份，`amount` 为元。`volume_source` 为手，`amount_source` 为千元。`signal_*` 仅根据已生效公司行动调整，用于生成策略信号；实际成交使用不复权价格。

## 公司行动

| 生效日 | 类型 | 参数 |
|---|---|---|
| 2022-09-02 | 份额合并 | 每旧份转换 0.36555 份，账户总份额向上取整；当日停牌 |
| 2025-01-15 | 现金分红 | 每份 0.037 元，01-14 登记，01-20 支付 |
| 2026-01-19 | 现金分红 | 每份 0.041 元，01-16 登记，01-22 支付 |

公告链接在 CSV 的 `source_url` 字段中。扩展样本日期时应同步公司行动。
