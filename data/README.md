# 数据与许可边界

正式版本附带一个明确命名的日频研究样本：[南方中证1000ETF（512100.SH）](../examples/data/zz1000/README.md)，以及对应的公司行动 CSV 和校验指纹。样本位于 `examples/data/zz1000/`，包含在 Git 仓库及源码分发包中；wheel 仅安装回测代码。

代码使用 MIT 许可证。行情的原供应商和上游再分发许可没有在现有记录中明确，本项目不把该行情自动标记为 MIT 开放数据。完整说明见样本 README。

其他本地资产仍不发布：`data/research/`、日线 / 各分钟数据湖、`ETF日线/`、`基金_复权因子/`、公告 PDF、历史报告。数据目录不自动进入分发包，只有上述命名样本为本次发布例外。

使用虚构行情可运行 [合成数据示例](../examples/README.md)；接入自己的真实行情见 [数据契约](../docs/data-contract.md)。
